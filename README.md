# JellyVerse

Your whole media universe in one app – Jellyfin films and shows, Navidrome music, radio, Live TV, requests, downloads and your homelab, on **Android phones and Android TV**.

## Get the app

- **Google Play** (recommended – updates arrive automatically)
  - Phone: https://play.google.com/store/apps/details?id=com.sridhar.jellyverse
  - Android TV: https://play.google.com/store/apps/details?id=com.sridhar.jellyverse.tv
- **APK downloads**: see [Releases](https://github.com/simpletoolsindia/jellyverse/releases) for every version's phone and TV APK and what changed.

## What's in this repository

This repository only hosts the public downloads and the radio station directory the app reads (`radio/stations.json`).
The app's source code is private.
