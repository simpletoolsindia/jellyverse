For developers

Build it yourself.

Kotlin 2.1, Jetpack Compose, Media3, Retrofit and Coil. One project with phone and TV flavors, covered by unit, UI and end-to-end tests.

git clone https://github.com/simpletoolsindia/jellyverse.git
cd jellyverse
./gradlew assemblePhoneRelease assembleTvRelease     # APKs
./gradlew testPhoneDebugUnitTest                     # unit tests

Requires JDK 21 and the Android SDK (compile SDK 36). Without a keystore.properties, release builds use the debug key.
